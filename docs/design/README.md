# Mockup copies

Copies of the `.dc.html` files from the M2g design canvas: <https://claude.ai/artifact/DcmNjZGDmLtgu7mwb8jyi5>. The canvas is the source of truth. When the two differ, the canvas wins.

They are here so the M2g steps can be built and reviewed next to the code. Each step refreshes them when it starts, and the last step deletes this folder. See `docs/design-direction.md`.

The files are kept as they come from the canvas, so Prettier skips this folder. They load their fonts from Google Fonts and need the canvas's `support.js`, so they don't render on their own; open the canvas to see them.
